No artigo de abertura desta promissora série, foi possível detalhar o Hive como uma solução extremamente eficiente no contexto de transformação e análise de grandes volumes de dados armazenados em sistemas de armazenamento distribuído.

## Download do Apache Hive

Como primeiro passo do processo de instalação do Hive, uma versão estável será escolhida diretamente do [site oficial](https://hive.apache.org/downloads.html) para que o download na máquina virtual Linux possa ser realizado. Assim, logado no Ubuntu, execute o comando abaixo para atualização dos pacotes do sistema:

```bash
sudo apt update -y
```

1) Ao longo do tempo, novas versões do Apache Hive continuam sendo lançadas pelos desenvolvedores. Para visualizar as versões disponíveis, é possível visitar o [site oficial de downloads](https://hive.apache.org/downloads.html) do Hive.

2) Para realizar o download do Hive, bastas executar o comando abaixo substituindo os valores de `x`, `y` e `z` de acordo com a versão desejada.

```bash
wget https://downloads.apache.org/hive/hive-3.1.2/apache-hive-x.y.z-bin.tar.gz
```

3) Para fins organizacionais, o conteúdo do repositório obtido será movido para o diretório `/opt`. Esta é uma boa prática considerando a instalação em diretórios do sistema que não estão diretamente vinculados a um usuário em específico.

```bash
sudo mv apache-hive-x.y.z.tar.gz /opt
```

4) Navegue até o diretório `/opt` e realize a extração do arquivo tarball através do comando:

```bash
cd opt
sudo tar xzf apache-hive-x.y.z.tar.gz
```

5) Na sequência, garantindo uma padronização dos softwares obtidos e facilitar o acompanhamento dos próximos passos de instalação deste tutorial, utilize o comando abaixo para renomear o diretório do hive:

```bash
sudo mv apache-hive-x.y.z hive
```

![image.png](https://cdn.hashnode.com/res/hashnode/image/upload/v1651200587228/vwc2xF5qQ.png align="left")

6) Considerando os passos exemplificados no [artigo de instalação do Hadoop](https://panini.hashnode.dev/instalando-e-configurando-o-ambiente-hadoop), um usuário de nome *hadoop* foi criado para ser o principal centralizador das operações no sistema. Dessa forma, modifique as permissões do diretório do Hive recém extraído para o usuário *hadoop*, garantindo assim uma maior organização em meio as operações relacionadas à estas duas ferramentas.

```bash
sudo chown -R hadoop:hadoop /opt/hive
```

**Observação:** esta alteração de permissão é extremamente importante para que o usuário *hadoop* possa acessar, configurar e modificar as variáveis de ambiente e propriedades do Hive. O resultado efetivo pode ser visualizado através do comando `ls -l` onde as permissões de cada diretório são mostradas no terminal:

![image.png](https://cdn.hashnode.com/res/hashnode/image/upload/v1651200614194/NH0vMhhPU.png align="left")

6) Por fim, altere o usuário do sistema entrando no usuário *hadoop* para os passos subsequentes.

```bash
su - hadoop
```

![image.png](https://cdn.hashnode.com/res/hashnode/image/upload/v1651200629464/2zbVdbeP6.png align="left")

## Inicializando o Hadoop e Criando Diretórios

Para uma configuração padrão do Hive, é necessário criar diretórios específicos no HDFS para que as propriedades de configuração do Hive possam ser estabelecidas posteriormente.

1) Inicialize o HDFS através do comando:

```bash
start-dfs.sh
```

![image.png](https://cdn.hashnode.com/res/hashnode/image/upload/v1651200836674/BG-W5RjIO.png align="left")

2) Inicialize o YARN através do comando:

```bash
start-yarn.sh
```

![image.png](https://cdn.hashnode.com/res/hashnode/image/upload/v1651200884133/0a2CYuLoy.png align="left")

3) Verifique se os *daemons* estão funcionando corretamente através da listagem dos processos java:

```bash
jps
```

![image.png](https://cdn.hashnode.com/res/hashnode/image/upload/v1651200902280/zm5cnzlO4.png align="left")

4) Com isso, utilize o comando abaixo para criar um diretório no HDFS para armazenamento de arquivos temporários do Hive:

```bash
hdfs dfs -mkdir /tmp
```

5) Na sequência, utilize o comando abaixo para criar um diretório padrão para armazenamento dos dados no Hive dentro do banco de dados *default*:

```bash
hdfs dfs -mkdir -p /user/hive/warehouse
```

6) Verifique se os diretórios foram devidamente criados:

```bash
hdfs dfs -ls /
hdfs dfs -ls /user/hive
```

![image.png](https://cdn.hashnode.com/res/hashnode/image/upload/v1651200969050/2krVvbccW.png align="left")


7) Configure as permissões necessárias de escrita e execução para os diretórios recém criados:

```bash
hdfs dfs -chmod g+w /tmp
hdfs dfs -chmod g+w /user/hive/warehouse
```

## Configuração das Variáveis de Ambiente e Propriedades

Com os insumos estabelecidos, é necessário agora aplicar algumas alterações relacionadas à configuração das variáveis de ambiente para o Hive e também de algumas propriedades adicionais. De forma geral, as configurações serão aplicadas em:

| Arquivo | Descrição | Variáveis Configuradas |
| :---: | :---: | :---: |
| *.bashrc* | Arquivo inicializado quando um usuário Linux realiza o login. Contém configurações a serem aplicadas na sessão do terminal. | `HIVE_HOME`, `PATH` |
| *hive-config.sh* | Arquivo de configurações básicas do Hive. | `HADOOP_HOME` |
| *hive-site.xml* | Armazena basicamente todas as configurações do Hive. Neste tutorial, serão propostas apenas algumas modificações pontuais. | `hive.metastore.warehouse.dir`, `system:java.io.tmpdir`, `system:user.name`, `javax.jdo.option.ConnectionURL` |

___

### Configuração do Arquivo .bashrc

1) Usando um editor de texto presente no sistema operacional, abra o arquivo `.bashrc`:

```bash
nano ~/.bashrc
```

2) Ao final do arquivo (dica: utilize `Ctrl + End`), adicione as seguintes configurações:

```bash
# Configuração de variáveis de ambiente para o Hive
export HIVE_HOME= "/opt/hive"
export PATH=$PATH:$HIVE_HOME/bin
```

**Obs:*** certifique-se que a variável `HIVE_HOME` aponte para a extração do Hadoop realizada nos passos anteriores.

![image.png](https://cdn.hashnode.com/res/hashnode/image/upload/v1651201055734/kkIWnxJzG.png align="left")

3) Salve e feche o arquivo

4) Execute o comando abaixo no terminal para ativar as configurações recém inseridas:

```bash
source ~/.bashrc
```
___

### Configuração do Arquivo hive-config.sh

1) Usando um editor de texto presente no sistema operacional, abra o arquivo `hive-config.sh`

```bash
nano $HIVE_HOME/bin/hive-config.sh
```

2) Ao final do arquivo (`Ctrl` + `End` pode ajudar), adicione o seguinte conteúdo para referenciar o local de instalação do Hadoop para que ambos os sistemas funcionem em conjunto:

```bash
export HADOOP_HOME=/opt/hadoop
```

**Obs:** certifique-se que a variável `HADOOP_HOME` aponte para a extração do Hadoop presente no sistema operacional. A informação disponibilizada acima pode ser diferente do que realmente existe em seu ambiente. Verifique onde o Hadoop está instalado e altere conforme sua pesquisa.

![image.png](https://cdn.hashnode.com/res/hashnode/image/upload/v1651201183771/Nc2hNg5jT.png align="left")

### Configuração do Arquivo hive-site.xml

1) Navegue até o diretório de configuração do Hive através do comando:

```bash
cd $HIVE_HOME/conf
```

2) Realize uma cópia do arquivo de *template* de configuração fornecido automaticamente pelo Hive através do comando:

```bash
cp hive-default.xml.template hive-site.xml
```

3) Utilizando um editor de texto, abra o arquivo `hive-site.xml` recém criado/copiado:

```bash
nano hive-site.xml
```

**Obs:** O arquivo `hive-site.xml` controla basicamente todos os aspectos operacionais do Hive e existe uma série de parâmetros e atributos que podem ser definidos. Para simplificar, será proposta apenas uma configuração direta do caminho padrão dos dados no Hive. Para mais informações, é possível consultar a [documentação oficial de configuração](https://cwiki.apache.org/confluence/display/Hive/AdminManual+Configuration#AdminManualConfiguration-HiveConfigurationVariables).

4) Com o arquivo aberto via editor de texto **nano**, utilize o comando `Ctrl` + `W` para procurar o texto `hive.metastore.warehouse.dir`. Pressione `Enter` após a digitação.

![image.png](https://cdn.hashnode.com/res/hashnode/image/upload/v1651201294489/Yr5hV0mwd.png align="left")

5) Verifique se o valor configurado para a propriedade `hive.metastore.warehouse.dir` aponta para o diretório padrão criado no HDFS para armazenar dados de tabelas criadas sob o banco de dados *default* (`/user/hive/warehouse`). Em caso negativo, modifique esta propriedade e inclua o valor adequado.

![image.png](https://cdn.hashnode.com/res/hashnode/image/upload/v1651201345125/-v_o-xM2Q.png align="left")

6) Para evitar erros de configuração de arquivos temporários do Hive, retorne ao início do arquivo `hive-site.xml` através do comando `Ctrl` + `Home` e abaixe o cursos até alcançar o interior da  chave`</configuration>`. Neste local, adicione as seguintes propriedades:

```bash
<property>
  <name>system:java.io.tmpdir</name>
  <value>/tmp/hive/java</value>
</property>
<property>
  <name>system:user.name</name>
  <value>${user.name}</value>
</property>
```

![image.png](https://cdn.hashnode.com/res/hashnode/image/upload/v1651201410385/wr2tqKxIJ.png align="left")
