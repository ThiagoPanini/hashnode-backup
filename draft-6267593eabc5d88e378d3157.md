## Instalando o MySQL

1) Como um primeiro passo importante antes de qualquer instalação de aplicativos e *softwares* no Linux, é preciso realizar a atualização dos pacotes do sistema através do comando:

```bash
sudo apt update -y
```

2) Assim, a instalação do servidor do MySQL poderá ser realizada através do comando:

```bash
sudo apt install mysql-server
```

![image.png](https://cdn.hashnode.com/res/hashnode/image/upload/v1650941364569/nhf5pLEnX.png)

**Observação:** neste ponto, o servidor do MySQL já está instalado na máquina de trabalho. Entretanto, uma configuração de instalação segura será realizada para garantir as boas práticas de utilização do MySQL. Esta instalação está baseada na execução de um comando específico fornecido com o pacote do MySQL que, por sua vez, solicitará ao usuário uma série de informações a respeito de tópicos de segurança, permitindo assim a tomada de alguma ações de acordo com os *inputs* passados pelo usuário.

3) Execute o comando abaixo para iniciar a instalação e configuração do MySQL em seu "modo de segurança".

```bash
sudo mysql_secure_installation
```

4) Neste ponto, uma série de questionamentos serão propostos para que o MySQL seja configurado da forma mais segura possível. Entre eles, é possível citar:

- Validador de senhas seguras
- Política de nível de segurança de senhas
- Remoção de usuários anônimos
- Desabilitar *login* remoto
- Remoção do *database* de testes
- Recarga dos privilégios de tabelas

Por padrão, a resposta “Y” ou “y” para todas as perguntas pode ser fornecida. Caso queira uma configuração diferente, basta responder as perguntas no terminal de acordo com as necessidades. Invariavelmente, a mensagem *"All done!"* será mostrada ao usuário ao final do questionário.

![image.png](https://cdn.hashnode.com/res/hashnode/image/upload/v1650941562659/mezpgAFP_.png)

5) Pronto! Para realizar o *login* com o usuário root através do comando:

```bash
sudo mysql
```

6) Para validar, execute o comando `SHOW DATABASES;` para listar os bancos de dados presentes no sistema:

![image.png](https://cdn.hashnode.com/res/hashnode/image/upload/v1650941693252/FfNOY71AI.png)

Apesar de instalado e operante, existem algumas ações que ainda podem ser implementadas para aprimorar a usabilidade do MySQL no geral e enriquecer tópicos relacionados a sua segurança. Estas ações serão indicadas na próxima seção.

## Configurando o MySQL

Nos tópicos abaixo, serão consolidadas algumas práticas relevantes no contexto da utilização segura do banco de dados MySQL. Entre as ações a serem recomendadas, estão:

1. Configuração de uma senha para o usuário **root**
2. Criação de um usuário específico para conexão ao banco de dados

___

### Configurando senha para o usuário root

Por padrão, nos sistemas Ubuntu que executam o MySQL 5.7 (e as versões posteriores), o usuário root do MySQL é automaticamente configurado para autenticar usando o plug-in `auth_socket`, permitindo assim sua conexão sem a necessidade de utilizar uma senha. Para mudar este comportamento, os passos necessários envolvem:

1) Realizar o login no MySQL utilizando o usuário root utilizando o seguinte comando:

```bash
sudo mysql
```

2) Para visualizar o método de autenticação configurado para cada usuário, é possível executar uma query na tabela `user` presente no banco de dados `mysql` instalado por padrão. Assim, no console, insira a seguinte consulta:

```sql
SELECT user, authentication_string, plugin, host FROM mysql.user;
```

3) No resultado obtido, será possível visualizar que o registro para o usuário **root** está vazio para a coluna `authentication_string`. Para alterar este comportamento, é possível executar o seguinte comando abaixo:

```sql
ALTER USER 'root'@'localhost' IDENTIFIED WITH caching_sha2_password BY 'password';
```

onde `password` é a nova senha escolhida para o usuário **root**.

4) Para validar a alteração, é possível executar a mesma consulta na tabela `mysql.user` representada pelo passo 2) e verificar se existe uma string de autenticação registrada para a coluna `authentication_string`.

5) Para recarregar as alterações, execute o comando abaixo:

```sql
FLUSH PRIVILEGES;
```

6) Digite `exit` para sair.

7) Uma vez configurada a senha, o usuário **root** deve agora realizar a conexão ao banco de dados MySQL utilizando o seguinte comando:

```bash
sudo mysql -u root -p
```

onde `-u` é a flag de parâmetro para informar ao banco que a tentativa de conexão será feita para o usuário a ser passado sequencialmente; e a flag `-p` indica que uma senha será informada posteriormente no terminal. Ao inserir as informações corretamente, o usuário estará então conectado ao banco de dados.

![image.png](https://cdn.hashnode.com/res/hashnode/image/upload/v1651017749659/Tk7HSiMOW.png)

### Criando usuário MySQL

Por vezes, criar um usuário dedicado e configurar permissões específicas de acesso ao banco de dados MySQL pode ser uma boa prática. Para realizar este procedimento, é preciso:

1) Logar com o usuário **root** no banco de dados e executar o comando abaixo com os parâmetros desejados de usuário:

```sql
CREATE USER 'paninitdev'@'localhost' IDENTIFIED BY 'password';
```

onde `paninitdev` é o nome do usuário criado e `password` sua senha.

2) Após a criação do usuário, é necessário configurar as permissões necessárias em um procedimento estritamente semelhante ao consolidado na seção anterior para o usuário **root**. Para o usuário recém criado, será proposta a configuração de todas as permissões do sistema, simulando um acesso de administrador. Para tal, ainda logado com o usuário **root**, basta executar o comando abaixo no MySQL:

```sql
GRANT ALL PRIVILEGES ON *.* TO 'paninitdev'@'localhost' WITH GRANT OPTION;
```

3) Para validar a existência do usuário e suas configurações, é possível consultar a tabela `mysql.user`, trazendo as colunas desejadas ou aplicando os filtros necessários para analisar as informações.

### O serviço mysql via systemctl

Para visualizar se o banco de dados MySQL está ativo no sistema, basta executar o comando abaixo no terminal Linux:

```bash
systemctl status mysql.service
```

Assim, é possível obter a resposta sobre a atividade do servidor.

![image.png](https://cdn.hashnode.com/res/hashnode/image/upload/v1651018151408/kowTen9f8.png)

Por fim, a relação de comandos abaixo pode ser utilizada para verificar a atividade do servidor, inicia-lo caso necessário e habilitar sua inicialização automática sempre que o sistema for inicializado:

```bash
# Verificar se o servidor MySQL está sendo executado
systemctl status mysql.service

# Inicializar o servidor MySQL
systemctl start mysql.service

# Habilitar a inicialização automática do servidor MySQL junto ao sistema
systemctl enable mysql
```

Para um aprimoramento gerencial do uso do MySQL como solução de banco de dados, a próxima seção deste artigo irá propor a instalação do sistema de gerenciamento MySQL Workbench. Com ele, será possível utilizar uma interface amigável para realizar as mais variadas operações no MySQL.

## Instalando o MySQL Workbench

O MySQL Workbench é uma interface visual que facilita a operação no MySQL, desde o gerenciamento de bancos de dados e tabelas até a execução de consultas em SQL. Sua instalação é simples e direta.

1) Com o terminal aberto, execute o comando abaixo para instalar o SGBD MySQL Workbench:

```bash
sudo snap install mysql-workbench-community
```

![image.png](https://cdn.hashnode.com/res/hashnode/image/upload/v1651018504609/pdUfCaXZB.png)

2) Para permitir uma conexão correta entre o MySQL Workbench e o servidor MySQL, execute o seguinte comando no terminal:

```bash
sudo snap connect mysql-workbench-community:password-manager-service :password-manager-service
```

3) Agora é possível acessar o MySQL Workbench como um aplicativo do sistema operacional. Procure na lista e abra o software.

![image.png](https://cdn.hashnode.com/res/hashnode/image/upload/v1651018538224/Z9lF5Z1Zw.png)

4) Selecione a conexão disponível na instância local (porta 3306).

![image.png](https://cdn.hashnode.com/res/hashnode/image/upload/v1651018549775/oqhyPG6C9.png)

5) Fornece a senha do usuário **root**

![image.png](https://cdn.hashnode.com/res/hashnode/image/upload/v1651018560403/KUT5cw8MM.png)

6) Pronto! Agora é possível executar consultas SQL no servidor MySQL através do Workbench!

![image.png](https://cdn.hashnode.com/res/hashnode/image/upload/v1651018575103/I2oZW5Rcj.png)
